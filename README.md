## ¿Qué son los Métodos Numéricos?
Cuando nos enfrentamos a problemas matemáticos complejos (es decir, de cálculo extenso,
difíciles de resolver analíticamente con el cálculo estándar), es de gran ayuda contar con
un sistema computarizado que nos ayude a realizarlos con mayor exactitud y de manera más
eficiente y rápida. 

Son **técnicas para formular problemas matemáticos** de manera que puedan ser resueltos 
con operaciones aritméticas y lógicas (facilitando su lectura y procesamiento por la 
computadora). 
	
En el caso de las **operaciones aritméticas**, se encuentran:
* la suma (+), resta (-), multiplicación (*), división (/), módulo (%).

Y en caso de las **operaciones lógicas**, se usa el sistema binario para poder "traducir"
las cantidades deseadas a un lenguaje más fácil de entender para la computadora. Las 
operaciones lógicas básicas son:
* AND (Conjunción): Las condiciones condiciones (variables) son verdaderas.
* OR (Disyunción): Cualquiera de las condiciones es verdadera.
* NOT (Negación): Se invierte el valor.
* XOR (OR EXLUSIVA): Da verdadero si las variables son distintas entre sí.

Esta simplificación abre paso a la resolución de muchos tipos distintos de problemas.

Las computadoras requieren almacenar datos para poder hacer cálculos con ellos.
