## ¿Qué son los Métodos Numéricos?
Cuando nos enfrentamos a problemas matemáticos complejos (es decir, de cálculo extenso, difíciles de resolver analíticamente con el cálculo estándar), es de gran ayuda contar con un sistema computarizado que nos ayude a realizarlos con mayor exactitud y de manera más eficiente y rápida. 
Son *técnicas de simplificación de problemas matemáticos* para ser resueltos con operaciones aritméticas y lógicas.
